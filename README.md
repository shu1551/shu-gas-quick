# GASクイック

Google スプレッドシートで、**棚（決まった手 133 本）と全シート共通のマイマクロを、一覧から一瞬で撃つ**道具です。ツール本体に AI（API キー・使用料）は抱えません。

- メニューの「⚡ GASクイック」→「操作窓を開く」で、右に操作窓が出ます
- 一覧に、日本語の名前で並びます
  - **シート**: そのシートのマクロ（「マクロを記録」で作った物も）
  - **マイ**: マイマクロ。Drive の「GASクイック マイマクロ」に置いた全シート共通の自分用マクロ（どのシートでも並びます）
  - **棚**: 表を整える・一発整形・並べ替える・色を付ける などの決まった手（133 本）
- **エディタを開かずに追加・修正・削除が完結**: 一覧の「＋追加」や「編集」から、普段のチャット AI（Gemini / ChatGPT 等）と「コピー → 貼り付け → 保存」でマイマクロを育てられます（構文チェック付き）
- **設定タブから新規ファイル作成**: ブック名を入れてボタンを押すだけで、GASクイック入りの新しいスプレッドシートをすぐ作れます
- 「直前を取り消す」で戻せます（マクロを撃つ前に、シートを丸ごと隠しシートへ控えます）
- 「マイマクロへ」で、シートのマクロをマイマクロへ昇格できます

## マイマクロの書き方

```javascript
// 選んでいる範囲を太字にする（もう一度押すと太字を外す）
// 棚: 太字にする, 選んだ所を太字
function 選んだ所を太字() {
  var list = SpreadsheetApp.getActive().getActiveRangeList();
  var first = list.getRanges()[0];
  list.setFontWeight(first && first.getFontWeight() === 'bold' ? 'normal' : 'bold');
}
```

- `function 名前()` で書きます。名前がそのまま一覧に出ます
- すぐ上の `// 説明` は一覧の説明に、`// 棚: 言い方, 言い方` は上の欄の言葉で当てるのに使います
- 名前の末尾が `_` の関数は部品として一覧に出しません
- 新しいマクロは「＋追加」画面の **「AI に頼む型（プロンプト）をコピー」** を使って Gemini 等に頼み、「貼り付け → 保存」するだけで先頭に登録できます

## 入れ方（Python も clasp も不要）

### 一番簡単な方法（Google Drive からコピーするだけ）

1. [GASクイック 大元をコピーする](https://docs.google.com/spreadsheets/d/1qXITXBGfveSytYLff49J4danMFdob0ax_tXneghCmhA/copy) を開いて「コピーを作成」
2. コピーした大元で「拡張機能 → Apps Script」→ 右上「デプロイ → 新しいデプロイ」→ 左上の歯車から **「ライブラリ」** を選んで「デプロイ」（初回 1 回だけ）
3. 大元シートに戻り、メニュー **「⚡ GASクイック → つなぎ用 JSON を表示（コピー）」** →「JSON をコピー」を押す
4. 大元シートの `はじめに` にあるリンクから [GASクイック テンプレートをコピーする](https://docs.google.com/spreadsheets/d/1jskvI-zVB1Anrtwvxp0AXeiXSZF4N1cEDqt2K3TWO5I/copy)
5. テンプレートの「拡張機能 → Apps Script」→「プロジェクトの設定」で `appsscript.json` を表示し、全選択して手順 3 の JSON を貼り付けて保存 → テンプレートを F5 で再読込すれば完了！
6. 2 枚目以降は、テンプレートの **「設定」タブ →「新規ファイルを作成」** からボタン一発で作れます

### 手で貼る（GitHub の `dist/ライブラリ版/` から導入）

`dist/ライブラリ版/` のファイルを Apps Script のエディタに貼って導入することもできます。手順は [dist/ライブラリ版/はじめに.txt](dist/ライブラリ版/はじめに.txt) にあります。

- `大元/` … 単体のプロジェクト「GASクイック 大元」に貼ってライブラリとしてデプロイ（1 回だけ）
- `つなぎコード/` … 使うシートのスクリプトに貼る（シートごと）

### 組み立ての道具（開発者向け）

`quick.py` は、棚の元と GAS の読み書きを、隣に置いた [shu-gas-manager](https://github.com/shu1551/shu-gas-manager) から借ります。

```
py quick.py engine-sheet         # 配布用の「GASクイック 大元」シートを作る・入れ直す
py quick.py template --release   # テンプレートのシートを作る・入れ直す（版でつなぐ）
py quick.py connect <シートのURL>   # 今あるシートにつなぎコードを置く
py quick.py dist                 # 手で貼る用のファイルを dist/ に書き出す
```

## 使う許可

初回に Google の許可を求められます。シートの読み書き・Drive（マイマクロを読む・作る・書き足す）・操作窓の表示に使います。
